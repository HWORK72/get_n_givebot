Асинхронный бот-ассистент трейдера для мониторинга котировок, визуализации рыночных графиков криптовалютной биржи ByBit и отслеживания ключевых торговых сессий.

### Архитектурные особенности:
* **Интеграция с ByBit Market API:** Запрос актуальных цен, объемов и генерация графиков торговых пар без задержек.
* **Сессионный планировщик:** Автоматические уведомления об открытии европейской торговой сессии (08:00 UTC) с максимальной рыночной волатильностью.
* **Форекс-монитор:** Напоминания об открытии глобального валютного рынка (22:00 UTC воскресенья).
* **Сетевая изоляция:** Архитектура, адаптированная для безопасного развертывания через защищенные Cloudflare Tunnels.

### Стек технологий:
* Python 3.12
* Aiogram 3.x / Aiohttp
* ByBit REST API (Сбор биржевых метрик)
* Asyncio (Фоновый планировщик событий)
